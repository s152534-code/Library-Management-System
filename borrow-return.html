Borrow and Return

Members can use this example form to request a book loan or record a return.

Transaction details

This is a practice form. Use fictional data only. The values are sent to httpbin in a new tab and are not saved in this website.

For a return request, leave the due date empty. For a new loan, choose a due date after the borrowing date.

Borrowing steps

  1. Choose an available book.
  2. Use an active member ID.
  3. Request a 14-day loan and return the book on time.

These are sample project rules, not official university library policies.
