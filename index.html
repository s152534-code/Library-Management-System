Home

Welcome to our Library Management System. This website is a course project by Red Team. It helps visitors view books and see examples of library services.

What can you find here?

  • A catalog with book titles, authors, and availability.
  • Forms for book records, borrowing, and member registration.
  • Tables showing example library records.

Some books in our collection

View the full book catalog

How to use the website

  1. Open the book catalog.
  2. Choose a book and read its details.
  3. Open the borrowing form to try a sample request.

This Part II website uses HTML and CSS only. Books and member records are fictional examples. Forms do not update the tables.
