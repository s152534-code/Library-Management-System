# Library-Management-System
Library Management System is a web-based solution designed to help schools, universities, and public libraries organize, manage, and provide access to library resources efficiently. The system will allow users to search for books, view availability, and manage borrowing and returning records. 


# Library Management System — Part III

COMP3700, Fall 2026 — Red Team

## Run the website
Extract the folder and open `index.html` in a browser. Keep an internet connection so the two Bootstrap CDN links can load. No installation is needed.

## Features
- Bootstrap 5.3.8 grid, forms, responsive navbar, carousel and modal.
- Book and member constructors, sample arrays, generated tables, add and search forms.
- A questionnaire with three different regular-expression validation rules.
- A library fine and printing calculator in OMR.
- A six-book sorting game with score feedback and restart.
- Three gallery photos with a four-second interval, and a sliding welcome banner showing the date and time when the page was opened.

The JavaScript files are in `js/`. They use ordinary functions, arrays, loops and form events. Short comments explain the main steps. Bootstrap is imported using a CSS link and a script link, as shown in Week 4. There is no vendor folder or custom CSS.

Records stay in JavaScript arrays only while their page remains open. Refreshing or navigating away restores the sample records. The dashboard and loan list show the original Part II sample snapshot. The contact form prepares an email; login and borrowing are local form demonstrations.
